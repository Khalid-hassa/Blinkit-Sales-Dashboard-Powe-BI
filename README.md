# Blinkit Sales Dashboard

Welcome to the Blinkit Sales Dashboard project! This repository features a comprehensive Power BI dashboard designed to analyze key sales and outlet performance metrics for Blinkit, providing valuable insights into various aspects of the business.

## Project Overview

The primary objectives of this project are:

1. **Sales Analysis**: Evaluate total sales and average sales per transaction to assess overall performance.
2. **Product Category Insights**: Analyze sales distribution across different item categories.
3. **Outlet Performance**: Assess performance metrics based on outlet size and type.
4. **Temporal Trends**: Examine sales trends over time to identify peak periods.
5. **Customer Preferences**: Understand customer preferences through metrics like average ratings and fat content analysis.

## Key Features

- **Total Sales**: $1.20 million
- **Average Sales per Transaction**: $141
- **Total Items Sold**: 8,523
- **Average Customer Rating**: 3.9 stars

## Dashboard Highlights

1. **Sales and Item Breakdown**:
   - Visual representation of total sales across various item categories, including fruits & vegetables, snack foods, dairy, and frozen foods.

2. **Outlet Size and Type Performance**:
   - Insights into sales, customer ratings, and item visibility across different outlet sizes and types, such as Grocery Stores and Supermarkets (Types 1-3).

3. **Establishment Year Trend**:
   - Analysis of sales trends over time, highlighting peak sales in specific years.

4. **Fat Content and Tier Analysis**:
   - Performance evaluation of low-fat and regular items, segmented by outlet tiers (Tier 1-3).

5. **Dynamic Filtering**:
   - Interactive filters for outlet location, size, and item type, allowing for flexible and detailed insights.

## Repository Contents

- `Blinkit-Dashboard.pbix`: The Power BI dashboard file containing all visualizations and analyses.
- `README.md`: Project documentation and overview.

## Getting Started

To explore the dashboard:

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/Khalid-hassa/Blinkit-Sales-Dashboard-Powe-BI.git
   ```
2. **Open the Dashboard**:
   - Ensure you have [Power BI Desktop](https://powerbi.microsoft.com/desktop/) installed.
   - Open the `Blinkit-Dashboard.pbix` file using Power BI Desktop to interact with the visualizations.
